# WhatsApp Sorry Message Automation

A simple Python automation project that sends
apology messages through WhatsApp Web.

## Features

- Enter mobile number
- Enter number of messages
- Enter custom apology message
- Automate WhatsApp Web
- Send repeated messages automatically.

## Technologies Used

- Python
- PyAutoGUI
- WhatsApp Web
